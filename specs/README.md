# specs/

The source of truth for Bragi. If code and spec disagree, the spec wins — or you change the spec in
the same PR ([13 §1, §7](13-agent-guide.md)).

Read them in order; the table with one line per document is in the
[root README](../README.md). Start at [`13-agent-guide.md`](13-agent-guide.md) if you are about to
implement something, and [`12-roadmap.md`](12-roadmap.md) to pick the work package.

Architecture decisions live in [`decisions/`](decisions) and are referenced from the specs they
affect.
