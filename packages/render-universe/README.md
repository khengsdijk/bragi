# @bragi/render-universe

The Three.js renderer for the Universe: your library mapped by sound, genre and mood, with
instancing for 100k+ points, lenses, constellations and the zoom transition into a single song
([08-universe.md](../../specs/08-universe.md)).

Same rules as [`@bragi/render-canvas`](../render-canvas): a framework-agnostic class that never
imports React, `WebGPURenderer` with a WebGL2 fallback, and an accessible tree that matches the
clusters ([11 §6.1](../../specs/11-ux-and-accessibility.md)).

**Status:** scaffold only. Filled by **WP-3.3**.
