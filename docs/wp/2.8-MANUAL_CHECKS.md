# WP-2.8 — Manual checks

Blind seam listening for the two-sided capabilities: `generate.inpaint` fills a gap
inside the song and `generate.transition` bridges a section boundary. Do this on
speakers or headphones you know, in a quiet room, at a comfortable level. There is
nothing to install: the bench writes the files.

## Regenerating the audio

The previews are not committed (13 §1.7); the bench renders the five fixture songs in
code and keeps the generated audio for listening. From the repository root, with
ACE-Step running:

```bash
scripts/ace-step-serve.sh                      # http://127.0.0.1:8001, PID in .bragi/ace-step/serve.pid
pnpm bench:generate --capability inpaint --backend ace_step --n 3 --keep-audio
pnpm bench:generate --capability transition --backend ace_step --n 3 --keep-audio
kill "$(cat .bragi/ace-step/serve.pid)"        # stop the ~17 GB model afterwards
```

Each run takes five to ten minutes on this Mac. It writes, under `bench-results/`
(git-ignored):

| Path | What |
|---|---|
| `audio/splices/inpaint-A.wav`, … | Inpaint previews: the context before the gap, the filled span, the context after it. |
| `audio/splices/transition-A.wav`, … | Transition previews: the song around the boundary, with the bridge in place of the section edges. |
| `audio/candidates/` | Each processed candidate alone (`inpaint-<song>-c<index>-seed<seed>.wav`, `transition-…`). |
| `audio/sources/` | The five fixture songs, for reference. |
| `audio/listening-order-inpaint.json`, `audio/listening-order-transition.json` | Label → song/candidate. **Do not open before rating.** |
| `generate-<timestamp>-ace_step-<capability>.json` | The full report: gates, both seam scores, offsets, timings, machine label. |

A quick dry run without the model (synthetic, no seam character worth rating):

```bash
pnpm bench:generate --capability inpaint --backend fake --fixtures pop,waltz --n 1 --keep-audio
```

**What the preview is.** The app's join, not the gate's scoring render: the context
up to the processed clip's start offset, the clip, then the context from the clip's
end offset. The clip already carries the gate's short fade-in at its head; the end
is handed back to the context. Nothing marks the seams.

## What to listen for

Listen once from ~10 s before the first seam if you can tell where it is, and once
from the start without skipping. Judge the **seams**, not whether you like the
generated bars.

- **Inpaint.** Two joins, one at each edge of the fill. Listen for a click or a small
  gap at either edge; a level step (the fill suddenly quieter or louder); a change in
  brightness or width; a rhythmic stumble (the beat or the hats hesitate); a chord
  that does not belong; and whether the fill sounds like a loop that jumps back to an
  earlier bar (repetition is fine, a jump is not).
- **Transition.** One join across a section boundary. Listen for a click or a gap;
  a level step; a bridge that starts or ends on the wrong beat; a chord that fights
  the outgoing or incoming section; and whether the incoming section starts on time.

Rate each file:

- **U — unnoticeable**: you could not tell where the generated audio starts and stops.
- **N — noticeable**: you heard a change but it is a musical one you would accept in
  a first take.
- **O — obvious**: a click, level step or stumble you would fix before showing the app.
