# WP-2.7 — Manual checks

Blind seam listening for `generate.extend` (09 §9 check 1, second half: the owner rates a kept
splice as "unnoticeable" in ≥ 60 % of accepted candidates). Do this on speakers or headphones you
know, in a quiet room, at a comfortable level. There is nothing to install: the bench writes the
files.

## Regenerating the audio

The previews are not committed (13 §1.7); the bench renders the five fixture songs in code and
keeps the generated audio for listening. From the repository root, with ACE-Step running:

```bash
scripts/ace-step-serve.sh                      # http://127.0.0.1:8001, PID in .bragi/ace-step/serve.pid
pnpm bench:generate --backend ace_step --n 3 --keep-audio
kill "$(cat .bragi/ace-step/serve.pid)"        # stop the ~22 GB model afterwards
```

The run takes seven to ten minutes on this Mac. It writes, under `bench-results/` (git-ignored):

| Path | What |
|---|---|
| `audio/splices/A.wav`, `B.wav`, … | The previews to rate: the song's last ~30 s, then the generated 8 bars, joined at the section boundary the app uses (crossfaded over the gate's 0.4–0.5 s crossfade). |
| `audio/candidates/` | Each processed candidate alone (`<song>-c<index>-seed<seed>.wav`). |
| `audio/sources/` | The five fixture songs, for reference. |
| `audio/listening-order.json` | Label → song/candidate. **Do not open it before rating.** |
| `generate-<timestamp>-ace_step.json` | The full report: gates, seam scores, timings, machine label. |

A quick dry run without the model (synthetic, no seam character worth rating):

```bash
pnpm bench:generate --backend fake --fixtures pop,waltz --n 1 --keep-audio
```

**Caveat from the bench.** The loudness match can drive a candidate far above full scale when the
model fades its last bars, and the 24-bit asset the app plays then clips (see "What the bench found"
in [2.7.md](2.7.md)). If a file sounds distorted, or its ending swells or hisses, write that in the
notes; it is that issue, not the seam you are rating.

## What to listen for

Each file plays the end of a song and then a generated continuation, joined the way the accepted
candidate will play as the song's new section: an equal-power crossfade at the song's end over the
gate's crossfade length (about 0.4–0.5 s). Nothing marks the join. Listen for: a click or a small gap at
the join; a level step (the new part suddenly quieter or louder); a change in brightness or width;
a rhythmic stumble (the beat or the hats hesitate); a chord that does not belong. Judge the
**join**, not whether you like the generated bars.

For each file, listen once from ~10 s before the end if you can tell where it is, and once from
the start without skipping. Rate:

- **U — unnoticeable**: you could not tell where the old audio stops.
- **N — noticeable**: you heard a change but it is a musical one you would accept in a first take.
- **O — obvious**: a click, level step or stumble you would fix before showing the app.
