# fixtures/audio

Tiny audio clips used by engine, DSP and analysis tests: **≤ 30 s each, ≤ 5 MB total** in git
([13 §6](../../specs/13-agent-guide.md)).

Every file needs an entry in [`SOURCE.txt`](SOURCE.txt) recording its origin.
Self-made or generated only. A generated fixture should ship the script that generates it, so
it can be reproduced rather than trusted.

**Status:** empty. First clips arrive with WP-0.4 (stretch spike) and WP-1.1 (engine conformance).
